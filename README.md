# TP INF232 EC2 - Application de gestion des inscriptions

## Description
Application web développée avec Streamlit pour collecter et analyser des données d’étudiants.

## Fonctionnalités
- Ajout d’étudiants (nom, âge, filière)
- Statistiques (moyenne d’âge, répartition)
- Visualisation des données

## Technologies
- Python
- Streamlit
- Pandas

## Lien de l’application
https://ton-app.streamlit.app
